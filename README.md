# FitScanProject

O **FitScan** é um sistema desenvolvido para academias, com foco no cadastro e acompanhamento dos dados e objetivos dos alunos.

## ✨ Funcionalidades

- 👤 Cadastro de alunos
- ⚖️ Registro de peso e altura
- 🎯 Definição de objetivos
- 📊 Cálculo e classificação do IMC
- 📋 Acompanhamento dos dados dos alunos

## 🛠️ Tecnologias

- React
- JavaScript
- CSS
- Java
- Spring Boot
- MySQL
